### 投影片 05 — Live Coding ① ：print，讓電腦開口說話
**時間：6:30 – 10:00（3.5 分鐘）**

- `print()` 的意思就是「印出來給我看」
- 要印的文字要用**引號 `" "`** 包起來（提醒電腦：這是一段話，不是指令）
- 先示範一行，再請大家改成自己的名字

**Live Demo 程式碼：**
```python
print("哈囉，世界！")
print("我是高中生，我正在寫程式")
```

**預期輸出：**
```
哈囉，世界！
我是高中生，我正在寫程式
```

**互動延伸（現場請學生改）：**
```python
print("我的名字是 小明")
```
**預期輸出：**
```
我的名字是 小明
```

**講者口白：**
「第一道菜：print。print 在英文是『印出來』的意思，就是叫電腦把東西顯示給我們看。注意：要印的話一定要用『雙引號』包起來，這是在跟電腦說『引號裡面是一段話，照原樣印，不要多想』。我打 `print("哈囉，世界！")`，按播放，看——它真的把字印出來了！現在換你們，把引號裡的字改成你自己的名字，按播放。看到自己的名字了嗎？恭喜，你剛剛寫了人生第一個程式。」

### 投影片 06 — 核心類比：變數 = 盒子
**時間：10:00 – 11:30（1.5 分鐘）**

- 變數就是一個**貼了標籤的盒子**，可以把東西放進去
- 標籤 = 名字（例如 `name`）；盒子裡的東西 = 值（例如 `"小明"`）
- 等號 `=` 不是數學的等於，是「**把右邊放進左邊的盒子**」
- 之後叫盒子的名字，就會拿出裡面的東西

**講者口白：**
「下一個工具：變數。聽起來很數學，但它其實就是一個貼了標籤的盒子。我準備一個盒子，貼上標籤叫 name，把『小明』這兩個字放進去。之後我只要喊一聲 name，電腦就會把盒子打開，把『小明』拿給我。特別提醒：程式裡的等號，不是數學的『相等』，而是『把右邊的東西，放進左邊這個盒子』。記住這句話，後面就不會卡住。」

### 投影片 07 — Live Coding ② ：變數（把東西放進盒子）
**時間：11:30 – 15:00（3.5 分鐘）**

- 建立盒子並放東西：`name = "小明"`
- 盒子可以放文字（字串，要加引號），也可以放數字（不用加引號）
- 把盒子和文字一起印出來

**Live Demo 程式碼：**
```python
name = "小明"
age = 16
print("我的名字是", name)
print("我今年", age, "歲")
```

**預期輸出：**
```
我的名字是 小明
我今年 16 歲
```

**重點提示（放在頁面側欄）：**
- `"小明"` 有引號 → 文字（字串）
- `16` 沒有引號 → 數字
- `print(... , ... )` 用逗號可以把好幾樣東西一起印

**講者口白：**
「來實作盒子。我寫 `name = "小明"`，這就是準備一個叫 name 的盒子，把『小明』放進去。再寫 `age = 16`，注意 16 沒有引號，因為它是數字，數字可以拿來算；而文字要加引號。最後我用 print 把它們印出來，中間用逗號隔開，電腦會幫我們自動空一格。按播放——名字和年齡都出來了。現在你只要改盒子裡的內容，整個句子就跟著變，這就是變數好用的地方。」

### 投影片 09 — PRIMM 橋段（下）：執行 + 探究，為什麼是「香蕉」?
**時間：17:00 – 19:00（2 分鐘）**

- **Run（執行）**：實際按播放鍵
- **預期輸出：**
```
香蕉
```
- **Investigate（探究）**：為什麼不是蘋果？
  - 同一個盒子 `box`，第二行把『香蕉』放進去時，**舊的『蘋果』就被擠出去了**
  - 盒子一次只能裝一樣東西；後放的會蓋掉先放的
  - 這叫「重新賦值」——換掉盒子裡的內容

**講者口白：**
「揭曉。按播放——答案是 B，香蕉。猜對的同學恭喜，猜 A 的也很合理，我們來搞懂為什麼。關鍵是：box 從頭到尾是『同一個盒子』。第一行放蘋果，第二行又把香蕉放進同一個盒子，蘋果就被擠出去了。盒子一次只裝一樣，後面放的會蓋掉前面的。所以最後拿出來的是香蕉。這個動作叫『重新賦值』，是程式裡超常見的事。剛剛經歷的『先猜、再跑、再想為什麼』，就是工程師學東西的方法。」

### 投影片 10 — 核心類比：input / print = 和電腦對話

### 投影片 11 — Live Coding ③ ：input 聊天小應用
**時間：20:30 – 24:00（3.5 分鐘）**

- 用 `input()` 問名字，把答案存進盒子，再用 `print()` 回應
- 這支程式同時用到了今天三樣工具：問一句、盒子、印出來

**Live Demo 程式碼：**
```python
name = input("請問你叫什麼名字？")
print("哈囉，" + name + "！很高興認識你")
print(name + "，歡迎來到程式的世界")
```

**執行過程（使用者輸入 `小華`）：**
```
請問你叫什麼名字？小華
哈囉，小華！很高興認識你
小華，歡迎來到程式的世界
```

**重點提示（側欄）：**
- 文字和盒子用 `+` 黏在一起時，兩邊都要是文字（字串）
- `input()` 收進來的內容，本來就是文字，可以直接黏

**講者口白：**
「最後一道菜，把三樣工具一次用上。第一行：input 問『你叫什麼名字』，你打的字會被存進 name 這個盒子。第二、三行：用 print 回應，這裡我用加號把『哈囉，』跟盒子裡的名字黏在一起。按播放——出現輸入框，我打『小華』按 Enter，看！它跟我打招呼，還叫得出我的名字。這就是一個會跟你互動的程式。換你們試試，輸入你自己的名字。」

## 教學設計備註

- **刻意略過**（避免新手過載）：迴圈、函式、物件導向、安裝環境與終端機（全程以 Google Colab 規避安裝痛點）。
- **最小知識集**：僅 `print` / 變數 / 字串與數字 / `input` 四項，全部在三段 Live Coding 中親手做過一次。
- **三大類比一致貫穿**：食譜=程式、盒子=變數、溝通=input/print，每個新概念都先給類比再給程式碼。
- **PRIMM** 段落（08–09 頁）採 Predict → Run → Investigate 完整流程，鎖定新手最易卡的「變數重新賦值」概念。
- **三重焦慮正面化**（02 頁）與**結尾 CTA**（15 頁）首尾呼應，強化「你做得到」的情緒安全感。

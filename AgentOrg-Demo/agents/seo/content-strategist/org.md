# Content Strategist — Org

## Hierarchy
```
User
  └─ SEO Manager
       ├─ Keyword Researcher   — 關鍵字探勘、搜尋量/難度、關鍵字分群
       ├─ Content Strategist   ←── THIS AGENT
       ├─ Technical Auditor    — 技術 SEO 稽核（索引、速度、結構化資料、Core Web Vitals）
       ├─ Analytics Reporter   — 自然搜尋成效數據分析與報告
       └─ Shared: Calculator   — 精確數值計算，跨團隊使用
```

## Collaboration

- **Keyword Researcher → Content Strategist**: Keyword Researcher 提供關鍵字、搜尋量、難度與分群資料，Content Strategist 消費這些資料規劃主題叢集與內容日曆。
- **Content Strategist → Technical Auditor**: Content Strategist 產出 on-page 規格（標題/meta/H 標籤/內鏈）後，Technical Auditor 可驗證實作面的技術可行性與索引狀態。
- **Content Strategist → Analytics Reporter**: Content Strategist 規劃的內容上線後，Analytics Reporter 追蹤其自然搜尋成效，回饋優化方向。
- **Content Strategist ∥ Content Strategist**: 不同主題叢集可並行規劃（不同 pillar 各自獨立）。

## When NOT to Pick This Agent
- 需要原創關鍵字探勘、搜尋量或難度估算、關鍵字分群 → **Keyword Researcher**
- 需要技術 SEO 稽核（索引、爬取、速度、結構化資料、Core Web Vitals）→ **Technical Auditor**
- 需要自然搜尋成效數據分析或產出 KPI 報告 → **Analytics Reporter**
- 需要實際撰寫部落格全文成品 → 文案/寫手（非本 team worker）
- 需要網站工程實作（CMS、前端、伺服器）→ 工程團隊
- 需要修改 agent 系統檔案 → **Agent Ops**
